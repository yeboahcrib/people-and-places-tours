# Travel Website MVP

This repository contains a static MVP travel website built with HTML, CSS, and JavaScript.

## Pages

- Home
- Trips
- Trip Details
- About
- Contact
- FAQ

## Project Structure

- `index.html`
- `trips.html`
- `trip-details.html`
- `about.html`
- `contact.html`
- `faq.html`
- `assets/css/styles.css`
- `assets/js/main.js`

## Next Steps

- Replace placeholder trip content with your real packages
- Connect each `Book Now` button to the matching WeTravel booking URL
- Add a backend later if you want inquiry storage, admin tools, or custom booking

## Git Workflow

- Make small commits as features are added
- Keep trip content and styling changes in separate commits when possible
- Create a new branch for bigger changes before merging into `main`
